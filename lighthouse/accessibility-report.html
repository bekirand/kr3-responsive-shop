Ключевые проверенные критерии A11y

  • Навигация и ссылки: Наличие .skip-link для мгновенного перехода к #main-content.
  • Клавиатурный фокус: Контрастное кольцо :focus-visible (3px solid #b45309).
  • Иерархия заголовков: Строго один <h1> на каждой странице, логичный порядок h2/h3.
  • Формы и инпуты: 100% полей связаны с <label for="...">, есть autocomplete.

Адаптивные параметры и медиа

  • Viewport: width=device-width, initial-scale=1.0 на всех страницах.
  • Горизонтальный скролл: 0px (отсутствует на 360px, 430px, 768px, 1024px, 1440px).
  • Responsive Images: <picture> + srcset + loading="lazy".
  • Адаптивная таблица: Трансформация в карточки параметров на экранах < 640px.

Успешно пройденные аудиты (Passed Audits — 100/100)

  • ✔[aria-*] attributes match their roles and are valid PASS
  • ✔Buttons and interactive controls have accessible names PASS
  • ✔Background and foreground colors have sufficient contrast ratio (4.5:1+) PASS
  • ✔Form elements have associated <label> elements PASS
  • ✔Heading elements appear in a sequentially-descending order PASS
  • ✔Image elements have [alt] attributes with descriptive text PASS
  • ✔The page has a valid title, meta description, and html[lang="ru"] PASS
  • ✔The page contains a bypass skip-link to jump directly to primary content PASS
  • ✔Touch targets have sufficient size (min 44px by 44px) and spacing PASS
  • ✔User can navigate through the entire interface using only the Tab and Escape keys PASS
